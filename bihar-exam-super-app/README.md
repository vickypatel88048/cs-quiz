# Bihar Exam Super App

Bihar-focused exam preparation platform. MVP includes Exams, chapter-wise Notes, MCQ Practice, Mock Tests, Jobs, Results and Admin dashboard.

## Stack
Next.js + React + TypeScript + Tailwind-ready CSS + Lucide icons.

## Run
npm install
npm run dev

## Roadmap
- MongoDB + API
- Admin authentication
- Exam/subject/chapter CRUD
- Notes editor
- MCQ CRUD and bulk upload
- Timed test engine and scoring
- Bookmarks and performance analytics
- Jobs/results publishing
